# PDF to AudioBook Generator

This repo is a product demo showing how client-side LLMs could be used to deliver new kinds of SaaS product features.

This demo will allow you to create an audiobook from any PDF. Pick a PDF from the library or select a PDF from your local computer, then click play.

This demo **does not use** any third-paty Ai platforms like OpenAI, Anthropic or ElevenLabs, all of the audio is generated locally inside your browser window.

### Local Set-up

```sh
git clone git@github.com:anthonybudd/AudioBook-Generator.git
cd AudioBook-Generator

npm install
npm run dev

open http://localhost:3000
```
